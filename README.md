# EKingLand — 全球市场看板

全球主要指数、黄金与外汇的日线聚合看板，跑在 Uppcoder Next.js 环境。

## 内容

- 各组分图（真实值，时间轴同步）：股市（7 大指数）、外汇（美元指数 + 6 组汇率）、贵金属（黄金、白银、铜）、GDP（全球前十经济体 + 全球），每组一张图、从上到下排列，共享同一时间轴；悬停联动显示各图同日数值与事件
- 每个子项可单独选（可跨分类多选）；分类复选框全选/全不选该组
- 底部事件轴与图表时间轴对齐（按日期定位的分类色点，悬停看全文，点击看详情）；悬停图表时提示里也显示当日事件
- 区间切换：1个月 / 3个月 / 6个月 / 1年 / 3年 / 10年 / 30年，默认 1 年；粒度：日 / 周 / 月 / 季 / 年（按周期末收盘价聚合），默认日
- 纵轴：对数/线性切换，默认对数
- 浅色主题；涨红跌绿

## 数据

- 行情：Yahoo Finance 公开接口（沪深300 走东财接口），日线，1996-11-10～，30 年；17 个市场品种（7 指数 + 贵金属 3 + 美元指数 + 6 汇率），白银（SI=F）与铜（HG=F）自 2000-08-30 起
- GDP：世界银行年度名义美元 GDP（NY.GDP.MKTP.CD），全球前十经济体 + 全球，1996–2025，每年一个点；共 28 个系列
- 区间切换：1个月 / 3个月 / 6个月 / 1年 / 3年 / 10年 / 30年，默认 1 年；粒度：日 / 周 / 月 / 季 / 年（按周期末收盘价聚合），默认日
- 事件：`public/data/events.json`（2023-11-10～2026-11-10，111 条；仅覆盖近 3 年）
- `/app/api/market` 服务端拉取、6 小时缓存，失败时回退到 `public/data/` 内置快照

## 每日更新

`../ekingland-market-data/update_daily.py` 每天拉取新增日线（本机定时任务跑），
数据文件在 `public/data/`，随部署更新。
