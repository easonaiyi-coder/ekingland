# EKingLand — 全球市场看板

全球主要指数、黄金与外汇的日线聚合看板，跑在 Uppcoder Next.js 环境。

## 内容

- 全球市场全品种走势叠加对比（归一化，起点=100）：7 大指数 + 黄金 + 美元指数 + 6 组汇率，15 条线同在一张主图，带重大事件标记点
- 区间重大事件轴（美国大选、美联储、非农、CPI、战争、政策等）
- 浅色主题；涨红跌绿

## 数据

- 行情：Yahoo Finance 公开接口（沪深300 走东财接口），日线，1996-11-10～，30 年
- GDP：世界银行年度名义美元 GDP（NY.GDP.MKTP.CD），全球前十经济体 + 全球，1996–2025，每年一个点
- 区间切换：1个月 / 3个月 / 6个月 / 1年 / 3年 / 10年 / 30年，默认 30 年；粒度：日 / 周 / 月 / 季 / 年（按周期末收盘价聚合），默认日
- 事件：`public/data/events.json`（2023-11-10～2026-11-10，111 条；仅覆盖近 3 年）
- `/app/api/market` 服务端拉取、6 小时缓存，失败时回退到 `public/data/` 内置快照

## 每日更新

`../ekingland-market-data/update_daily.py` 每天拉取新增日线（本机定时任务跑），
数据文件在 `public/data/`，随部署更新。
